# 🌲 숲속의 99일 밤

로블록스 「99 Nights in the Forest」에서 영감을 받은 3인칭 3D 숲속 생존 게임입니다.
어두운 숲 한가운데 모닥불을 지키며 **99번째 밤**까지 살아남으세요.

## 실행 방법

- **`dist/99-survival.html`** 한 파일을 내려받아 크롬으로 열면 바로 실행됩니다. 설치나 인터넷이 필요 없습니다.
- 저장소를 받았다면 `index.html` 을 열어도 됩니다 (`vendor/three.min.js` 를 같이 씁니다).
- `python3 build.py` 를 실행하면 `dist/99-survival.html` 을 다시 만듭니다.

키보드와 마우스로 하는 게임이라 컴퓨터에서 해야 합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D / 방향키 | 이동 (카메라가 보는 방향 기준) |
| Shift | 달리기 (기력 소모) |
| Space | 점프 |
| 마우스 | 시점 회전 (화면을 클릭하면 커서가 잠기고, ESC 로 해제) |
| E / 왼쪽 클릭 | 도끼질 · 열매 따기 · 모닥불에 통나무 넣기 · 고기 굽기 |
| Q | 먹기 (구운 고기 → 열매 → 날고기 순) |
| V / 오른쪽 클릭 (누르고 있기) | 손전등 |
| Enter / R | 게임 오버 뒤 다시 시작 |

## 규칙

- **하루**: 낮 1분 30초 + 밤 1분. 밤을 99번 넘기면 승리, 체력이 0이 되면 끝입니다.
- **모닥불**: 연료가 계속 줄고 밤에는 더 빨리 탑니다. 통나무 1개 = 연료 +14%.
  통나무를 12개 넣을 때마다 **모닥불 레벨**이 올라(최대 6) 바닥의 주황색 원(안전 범위)이 넓어집니다.
  불빛 안에는 사슴과 늑대가 들어오지 못하고, 배가 부르면 체력이 회복됩니다. 연료가 0이 되면 안전한 곳이 사라집니다.
- **나무**: 도끼로 4번 치면 쓰러지고 통나무 3개. 한 번에 10개까지 들 수 있고(등에 멘 통나무로 보입니다),
  벤 나무는 2분 30초 뒤 다시 자랍니다.
- **배고픔**: 계속 줄고, 0이 되면 체력이 닳고 느려집니다.
  덤불 열매 +12, 늑대 고기는 모닥불에서 구우면 +45 (날로 먹으면 +15 대신 체력 -10).
- **늑대**: 처음 5마리, 밤 3번마다 1마리씩 늘어 최대 14마리. 가까이 가면 쫓아와 뭅니다(밤에 더 빠르고 멀리 봅니다).
  도끼로 3번 치면 쓰러지고 날고기 2개. 1분 뒤 숲 어딘가에 다시 나타납니다.
- **사슴 괴물**: 밤마다 깨어나 불빛 밖의 플레이어를 사냥합니다. 달리기보다 조금 느리지만 밤이 거듭될수록 빨라집니다.
  닿으면 체력 -35. **손전등으로 정면을 비추면** 얼어붙었다가 도망갑니다. 불빛 안에 있으면 가장자리를 맴돌며 노려봅니다.
- **길 잃은 아이 4명**: 숲 가장자리 네 곳에 노란 표시를 띄우고 기다립니다. 가까이 가면 따라오고,
  모닥불까지 데려오면 구출(체력이 가득 찹니다).
- 오른쪽 아래 **나침반**이 모닥불 방향과 거리, 밤에는 사슴과의 거리를 알려 줍니다.
