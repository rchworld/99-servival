# 🌲 숲속의 99일 밤

로블록스 「99 Nights in the Forest」에서 영감을 받은 3인칭 3D 숲속 생존 게임입니다.
어두운 숲 한가운데 모닥불을 지키며 **나와 AI 팀원 4명, 모두 5명**이 **99번째 밤**까지 살아남는 게임입니다.

## 실행 방법

- **`dist/99-survival.html`** 한 파일을 내려받아 크롬으로 열면 바로 실행됩니다. 설치나 인터넷이 필요 없습니다.
- 저장소를 받았다면 `index.html` 을 열어도 됩니다 (`vendor/three.min.js` 를 같이 씁니다).
- `python3 build.py` 를 실행하면 `dist/99-survival.html` 을 다시 만듭니다.

키보드와 마우스로 하는 게임이라 컴퓨터에서 해야 합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D / 방향키 | 이동 (카메라가 보는 방향 기준) |
| Shift | 달리기 (기력 소모) |
| Space | 점프 |
| 마우스 | 시점 회전 (화면을 클릭하면 커서가 잠기고, ESC 로 해제) |
| E / 왼쪽 클릭 | 도끼질 · 공격 · 줍기 · 보물상자 열기 · 모닥불에 넣기/고기 굽기 · 분쇄기 · 제작대 · 창고 |
| Q | 먹기 (구운 고기 → 사과 → 당근 → 열매 → 케이크 → 날고기 순) |
| H | 붕대 / 구급상자 쓰기 |
| F | 총 쏘기 (소총이 있으면 소총, 없으면 리볼버) |
| T | 곰덫 설치 |
| G | 🌟 소환 — 배가 아주 큰 학생 (30초마다) |
| Z | 🧨 다이너마이트 던지기 |
| V / 오른쪽 클릭 (누르고 있기) | 손전등 |
| Enter / R | 게임 오버 뒤 다시 시작 |

## 규칙

- **하루**: 낮 1분 30초 + 밤 1분. 밤을 99번 넘기면 승리, 내 체력이 0이 되면 끝입니다.
- **모닥불**: 연료가 계속 줄고 밤에는 더 빨리 탑니다. 통나무 +14%, 석탄 +30%, 연료통 +60%.
  넣은 양만큼 **모닥불 레벨**이 올라(최대 6) 바닥의 주황색 원(안전 범위)이 넓어집니다.
  불빛 안에는 사슴·늑대·곰이 들어오지 못하고, 배가 부르면 체력이 회복됩니다.
- **가방(자루)**: 통나무·석탄·연료통·고철 아이템은 자루에 담습니다. 낡은 자루 10 → 좋은 자루 20 → 거대한 자루 40.
- **고철 아이템**: 숲에 떨어진 🔩볼트(고철 1) · 🔲**철판**(3) · 📻낡은 라디오(2) · 🌀고장난 선풍기(4) · 🛞타이어(2).
  캠프의 **분쇄기**에 넣으면 **고철**이 되어 캠프 창고에 쌓입니다. 제작대를 열 때도 들고 있던 고철 아이템을 자동으로 분쇄합니다.
- **음식**: 🍒열매 +12, 🥕당근 +15, 🍎사과 +18, 🍖구운 고기 +45, 🍰케이크 +100(체력 +30), 🥩날고기 +15(체력 -10).
  날고기는 모닥불 옆에서 E 로 굽습니다.
- **보물상자 40개**: E 로 열면 아이템 2~3개. 모닥불에서 먼 **보라색 상자**에는 리볼버·소총·강한 손전등·거대한 자루·철 갑옷·구급상자·케이크 같은 좋은 것이 들어 있습니다.
- **아침마다** 숲에 새 물건(고철·석탄·연료통·당근·사과)이 떨어집니다.

### 🍂 계절 (3분마다)

| 계절 | 모습 |
| --- | --- |
| 🌸 봄 | 나무마다 **분홍 꽃**이 피고, **꽃잎이 흩날리며 떨어집니다**. 비가 조금 더 자주 옵니다 |
| 🌴 여름 | 숲 전체가 **코코넛 나무**로 바뀝니다. 베면 통나무와 함께 **🥥 코코넛 2개**(배고픔 +22)가 나옵니다 |
| 🍁 가을 | 잎이 **빨강·주황·노랑**으로 물들고 **낙엽이 빙글빙글 떨어집니다** |
| ❄️ 겨울 | **눈**이 내내 내리고 땅과 나무가 하얗게 덮이며, 캠프 둘레와 숲 곳곳에 **눈사람 16개**가 나타납니다(봄이 오면 녹습니다). 추워서 모닥불이 30% 빨리 타고 배도 25% 빨리 고픕니다. 비는 오지 않습니다 |

봄 → 여름 → 가을 → 겨울 → 봄… 순서로 돌고, 바뀔 때 10초 동안 천천히 물듭니다.
화면 위쪽 패널에 지금 계절과 다음 계절까지 남은 시간이 표시됩니다.

### 🌧️ 비

- 봄·여름·가을에 **언제 올지 모르게** 내립니다(그친 뒤 40초~3분 사이 무작위, 30~90초 동안). 밤에는 **폭풍우**가 더 자주 옵니다.
- 비가 오면 하늘이 잿빛으로 어두워지고, 안개가 짙어지고, 땅이 젖어 번들거립니다.
- **모닥불이 빨리 탑니다** — 비 +55%, 폭풍우 +90%. 모닥불 보호막이 있으면 비를 훨씬 덜 맞습니다.
- 폭풍우에는 **천둥번개**가 쳐서 숲이 번쩍 밝아집니다.
- 빗소리 때문에 늑대·곰이 보는 거리가 20% 줄어듭니다.

### 🛠️ 제작대

모닥불 옆 제작대에서 E. 재료는 **내 가방 + 캠프 창고**를 함께 씁니다. (고철은 창고, 가죽은 늑대·곰에게서)

| 단계 | 만들 수 있는 것 |
| --- | --- |
| 1단계 | 좋은 도끼 · 창 · 곰덫 · 붕대 ×2 · 가죽 갑옷 · 좋은 자루 · 리볼버 탄약 · **제작대 2단계** |
| 2단계 | 튼튼한 도끼 · 강한 손전등 · 리볼버 · 철 갑옷 · 거대한 자루 · 구급상자 · **제작대 3단계** |
| 3단계 | 전기톱 · 소총 · 소총 탄약 · 모닥불 보호막(안전 범위 +4m, 연료 30% 덜 탐) |

### 👥 팀원 4명 (AI)

| 이름 | 하는 일 |
| --- | --- |
| 철수, 지아 | 🪓 나무를 베어 통나무를 가져옵니다 (불이 약하면 바로 넣고, 남으면 창고로) |
| 영희 | 🔩 고철 아이템·석탄·연료통을 주워 옵니다 (고철은 창고, 연료는 모닥불로) |
| 민수 | 🏹 늑대·곰을 사냥해 고기(불이 켜져 있으면 구워서)와 가죽을 창고에 넣습니다 |

팀원은 밤이 되거나 다치면 대개 모닥불로 돌아오고(가끔 깜빡합니다), 밤에 불이 약해지면 창고 통나무를 넣습니다.
짐승에게 물리면 맞서 싸우고, 쓰러지면 45초 뒤 캠프에서 다시 일어납니다.
창고의 음식은 창고 앞에서 E 로 꺼내 먹을 수 있습니다.

### 적

- **늑대**: 처음 5마리, 밤 3번마다 1마리씩 늘어 최대 14마리. 체력 3, 고기 2 · 가죽 1.
- **곰**: 처음 2마리, 밤 6번마다 1마리씩 늘어 최대 5마리. 느리지만 아프게 뭅니다. 체력 10, 고기 5 · 가죽 2.
- **사슴 괴물**: 밤마다 깨어나 불빛 밖에 있는 사람(나와 팀원)을 사냥합니다. 밤이 거듭될수록 빨라집니다.
  **손전등으로 정면을 비추거나 총을 맞히면** 얼어붙었다가 도망갑니다.
- **🐯 호랑이 · 🐍 구렁이**: 숲 깊은 곳(모닥불에서 70m 밖)에 한 마리씩 살고, 밤 8번마다 늘어납니다(최대 3마리씩).
  곰보다 **2배 아프게**(낮 44 · 밤 56) 물고, **모닥불 빛 안에도 들어옵니다.** 다만 자기 영역에서 너무 멀어지면 쫓기를 그만두고 돌아갑니다.
  호랑이 체력 20(고기 6 · 가죽 3), 구렁이 체력 16(고기 4 · 가죽 1). 사냥꾼 팀원도 이 둘은 건드리지 않습니다.
- **곰덫**: 밟은 늑대·곰을 7초 동안 묶고 피해 3. 닫힌 덫은 E 로 다시 겁니다.
- **무기 피해**: 낡은 도끼 1 · 좋은 도끼 1.5 · 튼튼한 도끼 2 · 창 2.5 · 전기톱 3 · 리볼버 3 · 소총 6.

### 🪺 까치 둥지와 은혜 갚은 까치

- 숲 곳곳의 나무 가지 끝에 **까치 둥지 16개**가 있고, 까치가 앉아 있습니다.
- 그중 몇 개는 **떨어질 뻔합니다**(기울어져 흔들리고, 위에 노란 표시가 떠 있습니다). 처음에 4개, 아침마다 1개씩 더 생깁니다.
  오래 두면 끝내 떨어지고 까치는 날아가 버립니다.
- 떨어질 뻔한 둥지 **가까이서 점프(Space)** 하면 둥지를 제자리에 고쳐 줍니다.
- 그 까치는 **은혜를 갚으려** 머리 위를 빙빙 돌며 따라다니다가, 호랑이나 구렁이가 나타나면 **달려들어 네 번 쪼아(피해 20)** 쓰러뜨리고, 힘을 다해 **숨을 거둡니다**.
- 둥지가 있는 나무를 베면 둥지가 떨어집니다. 팀원들은 둥지 나무를 베지 않습니다.

### 🌟 소환 (G) — 설탕 도망쳐!의 소환 아이템

- 늘 옆에 떠 다니는 **소환 별**. G 를 누르면 40m 안의 가장 위험한 적(호랑이·구렁이·나를 노리는 짐승·사슴 순) 앞에 **배가 아주 큰 학생**이 나타나 막아섭니다.
- 1초 뒤 **엉덩이 방귀**가 터져 근처 22m 안의 적을 모두 **38m 밖으로 날려 버립니다**(떨어지면서 피해 3, 사슴은 얼어붙습니다).
- 몇 번이든 쓸 수 있지만, 한 번 쓰면 **30초** 뒤에 다시 쓸 수 있습니다.

### 👶 지하 굴에 갇힌 아이 4명

아이를 구하기는 쉽지 않습니다.

1. 모닥불에서 **네 방향으로 뻗은 흙길**을 끝까지 따라가면 돌무덤 입구에 **⬇ 지하 계단**이 있습니다. E 로 내려갑니다.
2. 계단 아래는 기둥이 선 어두운 **곰 소굴**입니다. **곰 8마리**가 잠들어 있다가, 가까이 가거나 큰 소리가 나면 깨어나 달려듭니다(굴 속 곰은 다시 살아나지 않습니다).
3. 곰을 상대할 방법은 두 가지입니다.
   - **🧨 다이너마이트** — 숲 곳곳(6곳, 2개씩)에 빨간 묶음으로 떨어져 있고, 먼 보물상자에서도 나옵니다. **Z** 로 던지면 2초 뒤 **콰광!** 9m 안의 곰이 **모두 죽습니다**. 너무 가까우면 나도 다칩니다.
   - **🗡️ 푸른 검** — 숲 어딘가의 돌 받침대에 **푸른빛으로 빛나며** 꽂혀 있습니다. 뽑으면(E) 짐승에게 피해 **6**(곰은 두 번이면 쓰러짐).
4. 굴 안쪽 끝의 **단단한 문**은 도끼로는 꿈쩍도 안 합니다. **푸른 검으로 세 번** 치거나, **다이너마이트**를 문 가까이에 던지면 부서집니다.
5. 문 너머 **방 안에 아이**가 있습니다. 가까이 가면 따라오고, 함께 **⬆ 출구 계단**으로 올라가 모닥불까지 데려오면 구출(체력이 가득 찹니다).

굴 속에서는 나침반이 출구 계단을 가리킵니다. 비·눈·번개는 굴 안까지 들어오지 않습니다.

### 👥 팀원들은 그다지 똑똑하지 않다

- 밤이 되어도 **깜빡하고 모닥불로 안 돌아올 때**가 있습니다(40% 확률로 15~60초 동안 계속 숲에 남음). 그러다 사슴이나 늑대에게 당하기도 합니다.
- 낮에 가끔 **멍하니 딴짓**을 합니다("앗, 나비다!").
- 짐승이 달려들면 절반쯤은 **겁먹고 엉뚱한 쪽으로 도망**칩니다.
- 통나무를 들고 오다 **떨어뜨리기도** 합니다(땅에 떨어진 통나무는 주울 수 있습니다).

게임 서버가 있어야 해서 이 HTML 파일 하나만으로는 할 수 없습니다.
